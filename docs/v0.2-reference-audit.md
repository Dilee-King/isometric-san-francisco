# Transport projection reference audit — 2026-11-10

The deployed [Isometric Vancouver traffic module](https://vancouver.isoworld.xyz/traffic.js) was retrieved and inspected directly. Its `drawCar` section constructs vehicle corners in east/north/up metres using the road heading and a perpendicular side vector. Body and cabin boxes are projected independently, with directional side shading and physical vehicle dimensions. The map camera's elevation foreshortens every corner. Vehicles are ordered and clipped with source structure masks. The current implementation does not simply rotate a screen-space top-view icon.

This explains the earlier SF issue: only its forward length was foreshortened; width and shapes were drawn using screen rotation. The resulting axes were always perpendicular in screen space, even when the projected world axes should not be.

The revised SF implementation applies the geometric principle through its own existing arbitrary-azimuth camera and original surface meshes, including vessel hulls and aircraft fuselage/wings. No Vancouver code or artwork is copied. The downloaded reference files remain local research material outside the published source.

The live site credits its viewer ancestry separately; its reference attribution is not treated as a blanket license for deployed files. The user-facing relationship remains “Inspired by Isometric NYC and Isometric Vancouver.”
