# Bay Area artwork

The selected 1536 × 1024 ImageGen plates continue the v0.8.1 atlas. The first regional frames carry retained San Francisco, Oakland and Sausalito artwork. Later guides copy the overlap from completed neighbors. The 16 closer views use aerial guides projected into the same 39° camera. The paired weather artwork uses the existing city appearances as lighting references.

Each plate has its final prompt beside it. The [aerial source hashes](aerial-guide-sha256.json) record the USDA NAIP exports used for the closer guides. Placement, selected artwork hashes and runtime assets are in the [Bay Area manifest](../../public/map/v9-art/bay/manifest.json).

The regional canvas is 5120 × 3584 at 0.034 px/m. Closer plates use 0.272 px/m. The separate City view retains its 1.854545 px/m street-level artwork. [Assembly and verification](../../docs/VERIFICATION-full-bay.md)
