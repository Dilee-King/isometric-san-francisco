# Western waterfront artwork

Ten 1536 × 1024 native-scale daylight art plates extend the waterfront. The four contextual plates in `context/` cover broader margins at a lower density. The four selected wet-night edits are paired with their daylight plates. The checked-in PNGs came from the built-in imagegen workflow; adjacent prompt files retain the exact text. Native references are regenerated with `python tools/render_golden_gate.py` from the registered western source. The existing Wharf art is a style reference.

The bridge is drawn as a single registered layer by `tools/paint_golden_gate.py`. Western wet and night materials where there is no selected edit come from `tools/golden_gate_lighting.py`. A common water field unifies the four final appearances away from land and piers.
