# Assets and provenance

No map artwork is included in this revision.

Every future published asset must have a manifest record containing: source provider and identifier/URL; source acquisition and dataset dates; geographic bounds and coordinate system; camera version; model, settings and prompt where applicable; tile neighbors/parents; masks and manual corrections; author/reviewer; rights/attribution; output checksum; and review state.

Keep source access or capture permission separate from permission to train a model, derive an image, cache it or republish it. Use reviewed, permitted inputs. Do not import a reference site's artwork as San Francisco content.

Raw captures, generated tile pyramids and large model/data files live outside Git in versioned asset storage once selected. Git retains small reviewed fixtures, source/asset manifests and reproducible processing instructions. Secrets stay in local ignored configuration.
